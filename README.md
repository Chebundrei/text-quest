# Лесное приключение

Текстовый квест на Python: ты просыпаешься на развилке лесной тропы,
исследуешь локации, собираешь предметы, сражаешься с врагами, заводишь
друзей и находишь один из четырёх финалов.

## Автор

*Студент / ФИО / группа*  
*Дисциплина:* Программирование на Python  
*Год:* 2026

## Возможности

- 24+ локации: развилка, лес, болото, деревня, замок, горы, море,
  пещеры, кладбище, руины, драконье логово, лес фей, долина единорогов,
  логово волков, заброшенная деревня и другие.
- Подвалы в 4 зданиях с сундуками и шансом 20% найти **Странный ключ**.
- Внутренние помещения: таверна, дом старосты, храм, замок (тронный зал,
  библиотека, спальня), комнаты наверху.
- 11 выбираемых персонажей с уникальными стартовыми бонусами.
- Случайные события: дождь, находки, нападения.
- Боевые и мирные решения (тролль, дракон).
- Инвентарь, золото, опыт, уровни, здоровье.
- Четыре финала:
  1. **Спаситель королевства** — убить дракона и спасти принцессу.
  2. **Друг леса** — подружиться с волком, феей и единорогом.
  3. **Легендарный герой** — уровень 5+, 3000+ золота, победить дракона,
     призраков и тролля.
  4. **Побег в реальный мир** — найти Странный ключ и открыть им дверь
     в подвале.
